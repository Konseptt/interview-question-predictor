## 2024-06-25 - [Information Leakage in API Routes]
**Vulnerability:** The API routes (`src/app/api/predict/route.ts` and `src/app/api/predict/stream/route.ts`) were exposing internal error details, including external API statuses, raw response text, and internal error messages, directly in the HTTP response to the client. This leaked information could give attackers clues about the backend infrastructure and potential weaknesses.
**Learning:** Returning detailed error messages directly to the client can accidentally expose sensitive information. A generic error response should be returned instead, while preserving detailed error logs on the server side for debugging and monitoring purposes.
**Prevention:** Implement a pattern of logging raw error details internally on the server (e.g., using `console.error` with a distinct `[Security Log]` prefix or integrating with a proper logging service), and return a sanitized, generic error message (e.g., "Service unavailable") to the client. Ensure catch blocks do not blindly pass `error.message` to the response.
